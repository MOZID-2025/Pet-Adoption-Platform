# PetNest 🐾

## Project Name

PetNest - Pet Adoption Platform

---

## Purpose

PetNest is a full-stack pet adoption platform where users can add pets for adoption, send adoption requests, manage listings, and track adoption status through a personalized dashboard.

---

## Live URL

https://your-live-site-url.com

---

## Features

- User Authentication & Private Routes
- Add Pet Listing with Complete Pet Information
- Adoption Request System
- Dashboard for Managing Pets & Requests
- Approve / Reject Adoption Requests
- My Requests Tracking System
- Delete & Update Pet Listings
- Responsive UI for Mobile, Tablet & Desktop
- MongoDB Database Integration
- Protected API Routes with JWT Verification

---

## Technologies Used

### Frontend

- Next.js
